Button — one primary per view; secondary for cancel/back, ghost inside tables, danger for delete, accent (amber) only for "Prenotim i ri".

```jsx
<Button icon="plus">Prenotim i ri</Button>
<Button variant="secondary">Anulo</Button>
<Button variant="ghost" size="sm" icon="printer">Printo</Button>
```

Sizes sm 32 / md 38 / lg 44px. Labels are short Albanian imperatives (Ruaj, Printo, Anulo).
